# Fraud Detection - Bank Transactions

Project on fraudulent bank transaction detection using SAS Studio.
Dataset: credit card transactions (legitimate vs fraudulent).

## Project Overview

- Data loading and fraud proportion analysis
- Descriptive statistics by transaction type (fraud vs legitimate)
- Distribution visualization by class
- Naive classifier as baseline model
- Predictive models for fraud detection

## Methodology

- Exploratory Data Analysis (EDA) with PROC FREQ, PROC MEANS, PROC SGPLOT
- Naive baseline classifier (predict all transactions as legitimate)
- Evaluation metrics: sensitivity, specificity, accuracy
- Comparison of multiple classification models

## Stack

SAS Studio - Statistical Analysis - Machine Learning - Data Science - Finance
